---
name: evidence-synthesis
description: Turn verified paper findings into an evidence matrix and a requested report or short cited synthesis, preserving conflicts and gaps.
---

Noter prepares a matrix of findings, source spans, note IDs, analysis IDs, support/conflict, uncertainty and coverage. Distinguish calculated results from model interpretation. Preserve contrary passages and edition, period, region and language differences; unresolved conflict remains unresolved. Bibliographer can propose additional sources when the scholar requests the identified gap to be filled.

The main agent writes only the requested report or short passage from verified notes and claims. Run `shutong_paper_audit` first. Do not promote raw discovery, unreviewed analysis or a subagent's fluent summary into a supported claim. Keep each substantive sentence linked to the original source location and, for computed findings, the analysis run. Do not introduce new numbers, quotations or causal explanations while composing prose.

Use Chicago author-date citations from actual source metadata and locators. Do not invent missing pages or author names. Preserve confidence and qualify the scope: selected sources and displayed contexts do not represent an exhaustive literature review. Return missing evidence for further research. The scholar owns interpretation and final manuscript decisions; full-paper composition is not the default deliverable.
